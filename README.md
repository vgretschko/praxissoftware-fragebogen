# Fragebogen Praxissoftware Arbeitsmedizin

Fragebogen zur Anforderungsklärung für eine Praxissoftware für die arbeitsmedizinische Vorsorge: Vorsorgekartei nach ArbMedVV, Fristen- und Fälligkeitskontrolle, Vorsorgebescheinigungen, Import von Mitarbeiterlisten.

Online: https://vgretschko.github.io/praxissoftware-fragebogen/

Die Seite ist eine einzelne HTML-Datei ohne externe Abhängigkeiten. Antworten werden nur lokal im Browser zwischengespeichert und am Ende als Textdatei heruntergeladen.
